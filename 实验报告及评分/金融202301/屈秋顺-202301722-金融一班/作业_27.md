# 部署指南

## 一、环境准备

### 1.1 依赖安装

```bash
# 安装Cloudbase CLI
npm install -g @cloudbase/cli

# 安装项目依赖
npm install
```

### 1.2 环境变量配置

创建 `.env` 文件：

```env
# Cloudbase配置
TCB_ENV_ID=bank-crm-2026
TCB_SECRET_ID=your-secret-id
TCB_SECRET_KEY=your-secret-key

# 数据库配置
DB_HOST=localhost
DB_PORT=27017
DB_NAME=bank_crm

# Redis配置
REDIS_HOST=localhost
REDIS_PORT=6379

# JWT配置
JWT_SECRET=your-jwt-secret
JWT_EXPIRES_IN=7d
```

## 二、部署步骤

### 2.1 登录Cloudbase

```bash
# 使用密钥登录
tcb login --apiKeyId your-secret-id --apiKey your-secret-key

# 或使用浏览器登录
tcb login
```

### 2.2 初始化项目

```bash
# 创建并初始化环境
tcb env:create bank-crm-2026 --region ap-guangzhou

# 初始化项目配置
tcb init --appId bank-crm-2026
```

### 2.3 部署云函数

```bash
# 部署所有函数
tcb functions:deploy --all

# 或部署单个函数
tcb functions:deploy customer-api
tcb functions:deploy ticket-api
tcb functions:deploy analytics-api
```

### 2.4 配置API网关

```bash
# 创建HTTP访问路径
tcb service:create -f customer-api -p /api/customers
tcb service:create -f ticket-api -p /api/tickets
tcb service:create -f analytics-api -p /api/analytics

# 配置自定义域名
tcb service:domain:bind -d api.bank-crm.com -p /api
```

### 2.5 数据库初始化

```bash
# 导入初始数据
tcb database:import -p ./database/init_data.json

# 验证数据
tcb database:query "db.customers.find({})"
```

## 三、启动命令

### 3.1 开发环境

```bash
# 本地开发
npm run dev

# 启动后端服务
node server.js

# 启动前端服务（Vue）
cd frontend && npm run serve
```

### 3.2 生产环境

```bash
# 构建前端
cd frontend && npm run build

# 部署前端到静态托管
tcb hosting:deploy ./frontend/dist -e bank-crm-2026

# 启动云函数（自动部署）
tcb functions:deploy --all
```

### 3.3 定时任务

```bash
# 创建定时触发器
tcb functions:trigger:create \
  -f scheduled-task \
  -t timer \
  -c "0 0 2 * * *" \
  -d "每日凌晨2点执行数据同步"
```

## 五、运维管理

### 5.1 日志查看

```bash
# 查看函数日志
tcb functions:log -f customer-api

# 实时日志
tcb functions:log -f customer-api -t
```

### 5.2 监控指标

```bash
# 查看函数监控
tcb functions:monitor -f customer-api

# 查看数据库监控
tcb database:monitor
```

### 5.3 版本管理

```bash
# 查看函数版本
tcb functions:versions -f customer-api

# 回滚版本
tcb functions:rollback -f customer-api -v v2
```

## 六、故障排查

### 6.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 云函数部署失败 | 依赖缺失 | 检查package.json |
| 数据库连接失败 | 配置错误 | 检查环境变量 |
| API访问失败 | 权限配置 | 检查API网关设置 |
| 函数执行超时 | 资源不足 | 增加内存配置 |

### 6.2 错误日志

```bash
# 查看最近错误
tcb functions:log -f customer-api --filter error

# 查看特定请求日志
tcb functions:log -f customer-api --requestId xxx
```
