## 二、部署配置

### 2.1 项目结构

```
cloudbase/
├── functions/
│   ├── customer-api/
│   │   ├── index.js
│   │   └── package.json
│   ├── ticket-api/
│   │   ├── index.js
│   │   └── package.json
│   ├── analytics-api/
│   │   ├── index.js
│   │   └── package.json
│   └── scheduled-task/
│       ├── index.js
│       └── package.json
├── database/
│   └── init_data.json
└── config/
    └── cloudbaserc.json
```

### 2.2 部署命令

```bash
# 登录Cloudbase
tcb login

# 初始化项目
tcb init --appId bank-crm-2026

# 部署云函数
tcb functions:deploy customer-api
tcb functions:deploy ticket-api
tcb functions:deploy analytics-api
tcb functions:deploy scheduled-task

# 配置HTTP访问路径
tcb service:create -f customer-api -p /api/customers
tcb service:create -f ticket-api -p /api/tickets
tcb service:create -f analytics-api -p /api/analytics

# 配置触发器
tcb functions:trigger:create -f scheduled-task -t timer -c "0 0 2 * * *"
```
