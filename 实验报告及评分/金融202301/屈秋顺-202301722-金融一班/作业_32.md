# 智慧银行CRM系统API接口文档

## 一、接口概述

### 1.1 基础信息

| 项目 | 内容 |
|------|------|
| API版本 | v1.0 |
| 基础URL | https://api.bank-crm.com/api |
| 认证方式 | JWT Token |
| 数据格式 | JSON |

### 1.2 状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器错误 |

## 二、客户管理接口

### 2.1 创建客户

**URL**: `POST /api/customers`

**请求体**:

```json
{
  "name": "张三",
  "phone": "13800138000",
  "email": "zhangsan@example.com",
  "level": "普通客户"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 客户姓名 |
| phone | string | 是 | 联系电话 |
| email | string | 否 | 电子邮箱 |
| level | string | 否 | 客户等级，默认普通客户 |

**成功响应** (201):

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "customerId": 1,
    "name": "张三",
    "phone": "13800138000",
    "email": "zhangsan@example.com",
    "level": "普通客户",
    "registerDate": "2026-06-05T10:00:00Z",
    "createdAt": "2026-06-05T10:00:00Z",
    "updatedAt": "2026-06-05T10:00:00Z"
  }
}
```

### 2.2 查询客户列表

**URL**: `GET /api/customers`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认1 |
| size | int | 否 | 每页数量，默认20 |
| name | string | 否 | 客户姓名（模糊查询） |
| level | string | 否 | 客户等级 |

**成功响应** (200):

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "content": [
      {
        "customerId": 1,
        "name": "张三",
        "phone": "13800138000",
        "level": "普通客户"
      }
    ],
    "totalElements": 100,
    "totalPages": 5,
    "currentPage": 1
  }
}
```

### 2.3 查询单个客户

**URL**: `GET /api/customers/{customerId}`

**路径参数**:

| 参数 | 类型 | 说明 |
|------|------|------|
| customerId | long | 客户ID |

**成功响应** (200):

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "customerId": 1,
    "name": "张三",
    "phone": "13800138000",
    "email": "zhangsan@example.com",
    "level": "普通客户",
    "registerDate": "2026-06-05T10:00:00Z"
  }
}
```

### 2.4 更新客户信息

**URL**: `PUT /api/customers/{customerId}`

**请求体**:

```json
{
  "name": "张三",
  "phone": "13900139000",
  "email": "zhangsan_new@example.com",
  "level": "金卡客户"
}
```

**成功响应** (200):

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "customerId": 1,
    "name": "张三",
    "phone": "13900139000",
    "email": "zhangsan_new@example.com",
    "level": "金卡客户"
  }
}
```

### 2.5 删除客户

**URL**: `DELETE /api/customers/{customerId}`

**成功响应** (200):

```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

## 三、工单管理接口

### 3.1 创建工单

**URL**: `POST /api/tickets`

**请求体**:

```json
{
  "customerId": 1,
  "title": "咨询理财产品",
  "content": "想了解最新的理财产品信息",
  "priority": "medium"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| customerId | long | 是 | 客户ID |
| title | string | 是 | 工单标题 |
| content | string | 是 | 工单内容 |
| priority | string | 否 | 优先级：low/medium/high |

### 3.2 查询工单列表

**URL**: `GET /api/tickets`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码 |
| size | int | 否 | 每页数量 |
| status | string | 否 | 工单状态 |
| customerId | long | 否 | 客户ID |

### 3.3 查询单个工单

**URL**: `GET /api/tickets/{ticketId}`

### 3.4 更新工单状态

**URL**: `PUT /api/tickets/{ticketId}/status`

**请求体**:

```json
{
  "status": "processing",
  "assignee": "李经理"
}
```

### 3.5 关闭工单

**URL**: `PUT /api/tickets/{ticketId}/close`
